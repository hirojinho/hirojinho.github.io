I work on the systems that keep LLMs and high-throughput services reliable and cheap in production, and I build tooling meant to be driven by AI agents, not just clicked through a UI.

What I work on

Messaging infrastructure.

I own the messaging layer of a WhatsApp AI ordering platform. I led the migration from thousands of per-phone job queues to a single sender-Groups queue, which cut tail latency ~6× at near-zero send failure, and I built the observability around it (OpenTelemetry, PostHog, BigQuery → Metabase).

LLM systems.

Bringing model cost and latency down with deterministic fast-paths, retrieval and embedding work, and evaluation harnesses for a system whose output isn't deterministic.

Agent-operated software.

I build tools an AI agent can operate as a first-class user, and I increasingly build them by directing coding agents. marginalia is where I work this out.

Foundations.

TypeScript, Node.js, distributed systems, queueing and backpressure, observability. Starting a master's in formal methods, because I want systems I can reason about.
